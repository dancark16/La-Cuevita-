1. Levantar Postgres (Docker)
cd C:\tienda-backend
docker compose up -d
docker compose start
aa
Terminar docker
docker compose stop

Verifica que quedó corriendo:
docker ps


2. Correr el backend (Spring Boot)
cd C:\tienda-backend
mvn spring-boot:run

Ver las tablas de Postgres directamente (opcional)
docker exec -it tienda-postgres psql -U tienda_user -d tienda -c "\dt"
